# Установка би-лед линз и модулей

Установить можно самостоятельно по инструкции или доверить монтаж партнёрскому сервису (клиентам ORIONLIGHT — скидка 15% на работы).

## Что в комплекте

- линзы / модули в заводской упаковке с защитными колпачками;
- крепёж и переходные рамки под штатные посадочные места большинства автомобилей;
- инструкция по установке с фото-подсказками (видеоурок пришлём по запросу).

## Самостоятельная установка (2–4 часа)

1. **Демонтаж фары** — снять фару и аккуратно разобрать корпус. Прогреть герметик строительным феном для аккуратного отделения стекла.
2. **Извлечение отражателя** — демонтировать штатный отражатель или лампу и подготовить посадочное место под линзу.
3. **Установка линзы** — закрепить линзу через переходное кольцо и подключить разъёмы питания и управления (при наличии).
4. **Сборка и настройка** — собрать фару, загерметизировать шов и отрегулировать свет по разметке (корректор и регулировочные винты).

Важно: перед установкой отключите аккумулятор. Если нет уверенности в навыках — доверьте монтаж профессионалам.

## Советы по выбору

- **Размер линзы** — 1.5–1.7″ для узких фар, 2.5–3″ для большинства современных автомобилей.
- **Напряжение** — для грузовых и автобусов выбирайте 24V модели, для легковых — 12V.
- **Световой поток** — чем выше мощность в ваттах, тем ярче свет. Для города достаточно 45–55W, для трассы лучше от 60W.
- **Цветовая температура** — 5000–5500K комфортны для глаз, 6000K — холодный «ксеноновый» свет.
